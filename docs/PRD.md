## 一、产品定位

**一句话定义**：自媒体封面标题生成工具 —「选模板 → 改文字/图片 → AI 辅助设计 → 导出高清封面」全流程可视化编辑器。

**目标用户**：自媒体运营者、短视频创作者、电商运营、封面设计师，无需 PS 技能即可快速产出高质量封面图。

**核心价值**：
1. 无需设计经验：300+ 模板 + AI 辅助设计（一键美化/配色/构图）
2. 爆款标题库：120+ 预置标题（含 CTR 评分）+ 标题公式引擎
3. 全在线操作：浏览器打开即用，支持本地导入图片、模板打包分享
4. 桌面端：Electron 打包，离线可用，AI 抠图模型随包携带

**双端策略**：
- **Web 端**（Cloudflare Pages / EdgeOne Pages）：即开即用，K-means 抠图降级
- **桌面端**（Electron macOS DMG）：ONNX 模型完整可用，性能更好

## 三、技术架构

| 层 | 技术 |
|----|------|
| 前端框架 | React 18.3 + TypeScript 5.5 + Vite 5.4 |
| 状态管理 | Zustand 5 + persist（localStorage） |
| 样式 | TailwindCSS 3.4 + lucide-react |
| AI 抠图 | @imgly/background-removal（ONNX ISNet）+ K-means 降级 |
| 导出 | html2canvas + Canvas2D 背景引擎 + SVG 序列化 |
| 桌面端 | Electron 32 + electron-builder 25 |
| 后端 | Express（仅 mock API） |
